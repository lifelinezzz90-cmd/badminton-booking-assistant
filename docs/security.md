# 安全模型

## 信任边界

- 用户配置：可提交的示例只含四个非秘密字段；真实 `config/local.json` 被忽略。
- 密钥：CAS 密码、SMTP 授权码和会话快照使用 Windows DPAPI，绑定当前用户。
- 浏览器：WebBridge 只在本机回环接口工作；会话数据不写入受版本控制文件。
- 任务：安装器和卸载器只操作 `BadmintonBookingAssistant_*`。

## 安全默认

邮件关闭、自动付款关闭、部分时段与候补策略开启。解析器拒绝常见明文秘密字段。VPN 优先从开始菜单发现，避免把用户目录硬编码到公共配置。

## 发布检查

发布前执行 Node/PowerShell 语法检查、配置兼容测试、PlanOnly 非变异测试、README 示例检查和全历史 Gitleaks。另行扫描手机号、邮箱、用户名、绝对用户路径、Token、Cookie、日志与生成配置。

## 限制

DPAPI 防止静态文件直接泄密，但无法保护已经被同一 Windows 用户权限控制的进程。使用者仍需保护系统账户、浏览器会话和远程桌面访问。
